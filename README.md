# 🛍️ FastAPI Store API

Esta es una API REST construida con [FastAPI](https://fastapi.tiangolo.com/) para gestionar artículos de una tienda. Permite **crear, leer, actualizar y eliminar (CRUD)** artículos almacenados en una base de datos en memoria.

---

## 🚀 Características

- Añadir nuevos artículos
- Consultar la lista de artículos
- Consultar un artículo por su ID
- Actualizar artículos existentes
- Eliminar artículos
- Validación de datos con Pydantic
- Respuestas estructuradas y manejo de errores

---

## 🛠️ Tecnologías

- [FastAPI](https://fastapi.tiangolo.com/)
- [Uvicorn](https://www.uvicorn.org/)
- [Pydantic](https://docs.pydantic.dev/)
- Python 3.7+
